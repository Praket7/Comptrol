# Threat model

The OAuth bearer token is taken only from `COMPTROL_GRAPH_ACCESS_TOKEN` at request time; it is never written to disk, never logged, and every upstream error is redacted before it leaves the adapter, so the secret cannot leak through responses or audit payloads. Callers must grant least-privilege Graph OAuth scopes (Mail.Read for search and read, Mail.Send / Mail.ReadWrite only when mutation intents are enabled). Sending is the highest-risk surface: `mail.send` is R3, every recipient address is validated, subjects are confined to a single line, and attachment files must already exist under the declared 10 MB cap with their sha256 recorded so a substituted file cannot pass silently. No browser cookie extraction or reuse exists anywhere; only explicit `Authorization: Bearer` API calls are made.
