# Support boundary

Supported: `presentation.read`, `presentation.batch_edit` (text, notes, slide create/delete/reorder, image insertion, basic vector/text shapes, geometry/rotation, fill/line/font color and size), and `presentation.export` to `pdf`/`pptx` on Windows, macOS, and Linux when `python-pptx` is installed. Install its dependency into Comptrol's local adapter environment with `python3 -m pip install -r adapters/powerpoint/requirements.txt`. Image assets must resolve under `COMPTROL_PRESENTATIONS_ROOT` when that root is set. PDF export requires a local `soffice`/`libreoffice` binary (or `COMPTROL_SOFFICE_BIN`); otherwise it is refused honestly. Unsupported: animation effects, embedded audio/video authoring, SmartArt, macro/VBA execution, `.pptm` macro preservation, arbitrary file writes outside the declared scope, and in-place edits of `.pptm` sources.
