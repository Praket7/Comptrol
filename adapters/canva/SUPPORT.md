# Support boundary

**Preview.** The Connect API path (`design.list`, `design.read`, `design.page.list`, `design.export`) is supported. Element inspection and all edits (`design.element.inspect`, `design.text.update`, `design.image.insert`, `design.element.create`, `design.element.delete`, `design.element.group`) validate and bind through this adapter but apply only via the companion Canva App bridge, which is in preview until it passes production constraints (Canva review, preview-API graduation for design pages, and the VERIFY.md bridge checks); until then those intents return `design_editing_app_required` and change nothing.

Design listing supports query, ownership (`any`/`owned`/`shared`), limit, and continuation pagination; design reads return live metadata including edit/view URLs, thumbnail, page count, and revision. Page listing follows the Connect pages range parameters (limit up to 200, optional offset). Exports support `pdf`, `jpg`, `png`, `gif`, `pptx`, `mp4`, `csv`, `html_bundle`, and `html_standalone` with optional one-based page selection, bounded job polling, and per-file size plus sha256 artifacts.

Unsupported: full-screen coordinate replay and raw screen coordinates for any intent (never offered, even as a fallback); fuzzy design search or id guessing (only exact design-id binding); exports larger than the 128 MB total cap or jobs that do not complete within the 120 s poll bound (refused, never truncated); sort orders beyond the documented list parameters; and any design type or format combination the upstream API rejects (surfaced as `export_failed`/`upstream_error`).
