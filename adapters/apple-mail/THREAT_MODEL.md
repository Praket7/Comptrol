# Threat model

Script injection is closed by construction: only fixed templates ever reach osascript, payload fields are data quoted into typed slots (multi-line bodies become quoted segments joined with `& linefeed &`), payload keys outside the per-intent allowlist are refused, and any script-source key yields `arbitrary_script_refused`. No credential handling exists in this adapter; Mail sends through the user's own configured accounts, and the optional account slot only selects the sender identity within Mail. Attachment paths are confined under `COMPTROL_MAIL_ASSETS_ROOT` (absolute, resolved, symlink-safe) with a 10 MB cap and sha256 recorded, so a model cannot stage files from outside the declared scope. Sending is R3 and Automation-gated by macOS itself: first use prompts for Automation permission, and denial surfaces as `automation_permission_required`, never as a silent skip.
