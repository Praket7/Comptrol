# Threat model

Script injection is closed by construction: only fixed templates ever reach osascript, payload fields are data quoted into typed slots (bodies become quoted segments joined with `& linefeed &`), payload keys outside the per-intent allowlist are refused, and any script-source key yields `arbitrary_script_refused`. Binding is exact: a send resolves either one chat GUID or the first buddy matching a validated participant handle across services, so a message cannot drift to a nearby contact. Replay is blocked per chat: the client nonce (caller-supplied or generated) is recorded under the state directory after the first send, and repeating the same nonce on the same chat yields `duplicate_send_refused`. Attachment paths are confined under `COMPTROL_MAIL_ASSETS_ROOT` with a 10 MB cap and sha256 recorded. Sending is R3 and Automation-gated by macOS itself; denial surfaces as `automation_permission_required`, never as a silent skip. No credential handling exists; Messages sends as the signed-in user.
