# Blender adapter

The offline typed-operation runner uses Blender's official `--background --python` entry point. It generates a closed script from validated scene operations, requires a separate `.blend` output for edits, and never executes model-supplied Python. A live add-on bridge also exists (`comptrol_live_bridge.py`): it runs an authenticated local socket inside the already-open Blender process, queues every bpy mutation through `bpy.app.timers` onto Blender's main thread, and reports live readback. Both routes expose object inspection, common mesh primitives, transforms, basic Principled material values, object deletion, project save, and frame/still render. Saved outputs are checked for nonzero size; process exit alone is never proof.
