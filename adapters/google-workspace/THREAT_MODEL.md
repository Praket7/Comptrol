# Threat model

The OAuth bearer token is taken only from `COMPTROL_GOOGLE_ACCESS_TOKEN` at request time; it is never written to disk, never logged, and every upstream error is redacted before it leaves the adapter, so the secret cannot leak through responses or audit payloads. Callers must grant least-privilege OAuth scopes (read-only scopes for reads and exports, editing scopes only when mutation intents are enabled). No browser cookie extraction or reuse exists anywhere; only explicit `Authorization: Bearer` API calls are made. Revision safety comes from binding the current revisionId before each edit, guarding the single batchUpdate with WriteControl.requiredRevisionId, refusing stale expected_revision_id values without writing, and verifying the post-batch reread before reporting success.
