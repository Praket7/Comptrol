# Roadmap

The foundation now includes durable idempotency and reconciliation, a real macOS AX route, exact macOS application launch, opt in Windows and Linux semantic brokers, browser target discovery, bounded accessibility snapshots, event sequencing, bounded waits, checkpoints, trace replay, local pairing state, and a conformance harness.

The first release now includes a narrow live browser websocket route for exact target evaluation, navigation, fill, click, bounded waits, accessibility snapshots, history navigation, exact live tab close, sandbox upload, and sandbox download. macOS also has a semantic foreground route for reopening one exact closed Chrome group. Broader browser primitives, portable closed group restoration, remote transport, application adapters, signed publication, npm distribution, and Homebrew publication are later milestones. They are not represented as universal capabilities.
