# Roadmap

The foundation now includes durable idempotency and reconciliation, a real macOS AX route, Windows and Linux capability brokers, browser target discovery, event sequencing, bounded waits, checkpoints, trace replay, and a conformance harness.

The first release now includes a narrow live browser websocket route for exact target evaluation, navigation, fill, click, bounded waits, sandbox upload, and sandbox download. Broader browser primitives, remote pairing, application adapters, signed artifacts, npm distribution, Homebrew publication, and stable background input are later milestones. They are not represented as universal capabilities.
